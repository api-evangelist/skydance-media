# Skydance Media

> Skydance Media is a Santa Monica, California diversified entertainment company founded in
> 2010 by David Ellison, producing event-scale film, television, animation, sports and
> interactive entertainment. It merged with Paramount Global on 7 August 2025 to form
> Paramount Skydance Corporation; skydance.com continues as the label site for the Animation,
> Film, Television, Sports, Interactive and New Media divisions. Skydance publishes no
> developer program, no API documentation, no SDK and no OpenAPI of its own. The only
> machine-readable, anonymously readable surface on its own host is the WordPress REST API at
> skydance.com/wp-json — the CMS content API behind the label site.

## APIs

- [Skydance Media Content API (WordPress REST wp/v2)](https://skydance.com/wp-json/wp/v2): The
  anonymously readable WordPress REST API behind skydance.com — pages, the media library,

## What does not exist

Recorded so an agent does not go looking. All probed 2026-08-05.

- No developer portal, API documentation, API reference, API key or signup. api.skydance.com
  and developer.skydance.com do not resolve.
- No SDK or client library in any registry. The `skydance` packages on npm and PyPI belong to
  an unrelated Wi-Fi lighting brand.
- No GitHub organization (github.com/skydance, /skydance-media, /skydanceinteractive,
  /skydancegames all 404).
- No `/.well-known/` documents at all — no security.txt, no openid-configuration, no
  agent-card.json, no agent.json, no ai-plugin.json, no api-catalog.
- No MCP server, no A2A agent card, no GraphQL endpoint, no AsyncAPI, no webhooks.
- No status page, no changelog, no deprecation policy, no SLA, no trust center.
- The film, television, animation, sports and interactive title catalog is NOT in the REST
  API. Those are custom post types that were never REST-registered; they appear only in
  https://skydance.com/sitemap_index.xml and in the rendered HTML.
